# Sistema de Control de Aforo para Gimnasios

## Descripción
Sistema de información para la automatización del control de acceso y gestión de aforo en tiempo real para gimnasios.

## Tecnologías
- React (Frontend)
- Node.js/Express (Backend)
- PostgreSQL/Supabase (Base de Datos)
